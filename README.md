# EKF with Outlier Detection for Unicycle Robot

## Overview
This repository contains a Python-based simulation of an Extended Kalman Filter (EKF) applied to a unicycle mobile robot. The primary focus of this project is to perform state estimation (Localization/SLAM) by fusing heterogeneous sensor data (proprioceptive IMU and exteroceptive Camera) while robustly handling sensory outliers and noise spikes.

## Key Features
*   **Unicycle Kinematics:** Realistic mathematical modeling of a differential-drive-like unicycle robot, offering a perfect balance between physical realism and mathematical complexity.
*   **Extended Kalman Filter (EKF):** Fuses high-frequency IMU data (prediction) with lower-frequency Camera data (update) to estimate the robot's state and compensate for drift over time.
*   **Robust Outlier Rejection:**
    *   **IMU (Proprioceptive):** Utilizes a sliding-window statistical approach to compute local means and covariances. It correctly identifies isolated sensor spikes while adapting to actual sudden maneuvers.
    *   **Camera (Exteroceptive):** Employs an innovation-based approach directly integrated with the EKF's predictive architecture. 
    *   Both approaches leverage the **Mahalanobis Distance** and **Chi-Square** thresholding to discard corrupted measurements without compromising the filter's stability.

## Repository Structure
*   `src/unicycle_estimation.py`: Main simulation script containing the unicycle kinematics, simulation loop, and CSV logging functionality.
*   `src/kalman_filter.py`: Core implementation of the Extended Kalman Filter equations (Prediction and Update steps).
*   `src/outliers_detection.py`: Contains the `IMUOutlierRejector` and `CameraOutlierRejector` classes for robust filtering.
*   `src/plot.py`: Script for parsing the generated CSV logs and creating visual performance metrics (e.g., IMU spike detection graphs, confusion matrices).
*   `src/dati_sensori.csv`: Log output generated by the simulation containing ground truth, estimates, and outlier detection flags.
*   `report/`: Contains the Quarto (`.qmd`) academic report detailing the theoretical foundation, sensor mathematics, and final results.

## Getting Started
1.  Ensure you have Python 3.x installed along with necessary dependencies (`numpy`, `scipy`, `matplotlib`).
2.  Run the main simulation to generate the sensor data logs:
    ```bash
    python src/unicycle_estimation.py
    ```
3.  Generate the results and plots to validate the outlier rejection:
    ```bash
    python src/plot.py
    ```
